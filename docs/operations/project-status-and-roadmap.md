TCP probe از این شبکه حتی برای پورت استفاده‌نشده handshake نشان داد، ولی HTTP مستقیم صفر بایت/timeout بود؛ اثبات firewall عمومی از آن استنتاج نشده است. شاهد binding محلی مستقل تأیید شده است.
